# 🤖 SarthiAI

An AI-powered chatbot built with the MERN Stack and Google Gemini API.

SarthiAI is a modern AI assistant that provides intelligent, real-time conversations with a clean and responsive interface. It supports chat history management, new conversations, and is deployed online using Render.

## ✨ Features

- 🤖 AI-powered conversations with Google Gemini API
- 💬 Start a New Chat anytime
- 💾 Automatically saves chat history
- 🗑️ Delete chat history
- 📱 Responsive and modern UI
- ⚡ Fast and smooth user experience
- ☁️ Live deployment on Render
